# E-Commerce Product Management System

## Overview
This project is a web-based E-Commerce Product Management System designed to handle product catalogs, customer registrations, shopping carts, and order management. The system provides full CRUD (Create, Read, Update, Delete) capabilities for administrators and a seamless shopping experience for customers.

## Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** PHP
- **Database:** MySQL
